# Copywren — Behavior Specification

What Copywren does, written precisely enough to build and test against. Code comments cite
sections as `SPEC §n`. Copywren uses its own names, text, icons and sounds.

---

## 1. Scope

**In scope (v1):** background clipboard capture; history with retention; pinboards; search with
smart tokens; floating popup at the text cursor; direct paste with plain-text variant; quick paste
⌘1–⌘9; Paste Queue (Copywren's name for collecting copies and pasting them in order); pause with auto-resume; privacy filters; screen-sharing hiding; menu bar item; settings window;
local SQLite storage.

**Out of scope (v1):** iCloud sync and shared pinboards, AI suggestions, MCP
server, OCR, link-preview downloads, image/text editing, Handoff, App Intents, licensing, auto-update.

## 2. Data model

* **Clip contents** = an ordered list of pasteboard items. Each item is an ordered list of
  `(type identifier, bytes)` pairs. Everything captured is replayed on paste, so fidelity is kept.
* **Item**: `id`, `kind` ∈ {text, link, image, file, color}, `title` (optional user name),
  `preview_text` (≤ 2 000 chars, used for search and display), `checksum` (SHA-256 over the
  kind and the primary content: the text, the URL, the file paths or the primary image bytes,
  so volatile side types don't defeat dedupe), `created_at`, `timestamp` (last copied or used; drives ordering),
  `source_bundle_id`, `source_app_name`, `pinboard_id` (null means a history item),
  `pin_order`, `char_count`, `image_width`/`image_height`, `file_count`.
* **Pinboard**: `id`, `name`, `color` (one of 8 palette indices), `position`.
* **App**: `bundle_id`, `name`, `color` (derived from bundle ID), `icon_png` (optional).

## 3. Capture behavior

1. Every **500 ms** read the pasteboard change count. If it hasn't changed, do nothing.
2. If it changed: skip when **paused**, or when the change was made by Copywren itself (Copywren records
   the change count after its own writes). Changes made before launch, or while paused, are never
   captured: the current count becomes the baseline at launch and on resume.
3. Read every item and every type. Skip the capture when any type is in the ignored set:
   * confidential (setting on by default): `org.nspasteboard.ConcealedType`, `com.agilebits.onepassword*`
   * transient (setting on by default): `org.nspasteboard.TransientType`,
     `org.nspasteboard.AutoGeneratedType`, `de.petermaurer.TransientPasteboardType`,
     `com.typeit4me.clipping`, `Pasteboard generator type`
   * user-added types.
4. Skip when the frontmost app's bundle ID is in **Ignored Applications**. Defaults are the Keychain
   Access and Passwords apps. A `org.nspasteboard.source` type, when present, overrides the
   frontmost app as the source.
5. Drop unusable payloads: no items, or more than 50 MB in total. Drop internal or dynamic types
   (`dyn.*`) when other types are present.
6. **Classify**, in this order: file URLs → `file`; a single image type (PNG, TIFF, JPEG, HEIC, PDF
   image) with no file URL → `image`; a string that is a single colour literal (`#RGB`, `#RRGGBB`,
   `#RRGGBBAA`, `rgb()`/`rgba()`, `hsl()`) → `color`; a string or `public.url` that is a single
   http(s), mailto or ftp URL with no whitespace → `link`; any other string or RTF → `text`. Otherwise
   the clip is not captured.
7. **Dedupe**: if a *history* item with the same checksum exists, move it to the front (update
   `timestamp` and source app) instead of inserting a copy. Pinboard items are never touched by capture.
8. After inserting, apply retention (§5).
9. If the Paste Queue is open, also append the new clip to the queue (§6).

## 4. Popup and interaction

Copywren uses a compact floating popup next to the text cursor, in the spirit of the clipboard
history panels on other desktop systems.

* Activation (default **⇧⌘V**, configurable) toggles the popup. The app that was frontmost when the
  popup opened is remembered as the **paste target**.
* The popup is a borderless, non-activating floating window of 380 × 520 pt with rounded corners.
  It opens just below the focused text cursor (asked of the frontmost app through Accessibility:
  `AXFocusedUIElement` → `AXSelectedTextRange` → `AXBoundsForRange`). If there's no caret, it falls
  back to the focused single-line field's frame, then to the mouse pointer. It flips above the anchor
  when there's no room below and always stays 8 pt inside the screen's visible area. It joins all
  Spaces, works over full-screen apps and is excluded from screen capture unless "Show during screen
  sharing" is on. Dragging its header moves it for the rest of that showing.
* It closes when it loses key status, on Esc (Esc first clears a non-empty search), on its × button,
  or after a paste. Each time it opens, the newest card is selected and the list scrolls to the top.
  The search text is kept unless the popup has been closed for more than 60 s.
* **Layout**, top to bottom: header (icon, name, Paste Queue and pause indicators, settings, close) ·
  search field · tabs (Clipboard first, then pinboards in order, "+" new pinboard) · a vertical,
  virtualized list of cards · footer (item count and key hints).
* **Cards**, newest first, show a meta line (source-app icon or colour dot, app name, relative time,
  and a "⋯" button on hover or selection), the item's custom title if it has one, and a body. Text
  shows up to 4 rows. Links show the host and URL. Images show a thumbnail of at most 332 × 140 pt
  with its pixel size. Colours show a swatch and the value. Files show up to 3 names with extension
  badges, then "and N more". Holding the quick-paste modifier shows ⌘1…⌘9 badges on the first nine
  cards in view.
* **Keyboard**

  | Keys | Action |
  |------|--------|
  | ↑ / ↓ | Move selection (doesn't wrap) |
  | ⌘↑ / ⌘↓, Home / End | First / last item |
  | Page Up / Page Down | Move by 5 |
  | ← / →, Tab / ⇧Tab, ⌘] / ⌘[ | Previous / next tab |
  | Return | Paste selected (to the target app, or to the clipboard if direct paste is off or Accessibility is untrusted) |
  | ⇧Return | Paste selected as plain text |
  | ⌘1…⌘9 | Quick paste the Nth card in view (⇧ also gives plain text) |
  | ⌘C | Copy selected to the clipboard only, then close |
  | ⌘⌫ / Delete | Delete selected (pinboard items: remove from the pinboard) |
  | ⌘O | Open link or file |
  | Space | Toggle the large preview of the selected item |
  | ⌘R | Rename the selected item |
  | ⌘N | New pinboard (typed inline in the tab bar) |
  | ⌘, | Settings |
  | printable text | Starts or continues the search (⌫ deletes a character, ⌥⌫ a word) |
  | Esc | Clear search, else close |
* **Mouse**: a single click pastes (⇧-click pastes plain text). "⋯" or right-click opens a context
  menu (Paste, Paste as Plain Text, Copy, Open / Show in Finder for links and files, Rename, Preview,
  "Pin to" / "Move to" pinboard chips with "+ New Pinboard", Delete / Remove from Pinboard). Dragging
  a card onto a pinboard tab pins it there. Inside a pinboard, dropping a card on another card
  reorders it. Pinboard tabs have a context menu: Rename, colour, Delete (with confirmation).
* **Pinning** copies a history item into the pinboard; the history item stays (a design choice). Pinning an item that is already on a pinboard moves it. Pinning content the target pinboard
  already holds doesn't duplicate it. Pinboard items are ordered by `pin_order` (new pins first) and
  are never removed by retention or "Erase History".

### 4.1 Paste action

1. Write the item's stored representations to the general pasteboard. For plain text, write only
   `public.utf8-plain-text` (the text, or the URL string, or file paths joined by newlines). Record
   the resulting change count as self-made.
2. Move the item to the front of history (`timestamp = now`). For pinboard items, update their source
   history twin when the checksum matches.
3. Hide the popup. When direct paste is on and the process is Accessibility-trusted, re-activate the
   target app if it isn't frontmost, wait about 80 ms, then post ⌘V key-down and key-up events with
   the Command flag.
4. When direct paste is on but trust is missing, prompt for trust once per launch. The item stays on
   the clipboard ("copy only" fallback).

## 5. Retention

The setting "Keep history" ∈ {Day, Week, Month, Year, Forever}, default Month. After every capture
and at launch, history items older than now − period are deleted (by `timestamp`). If lowering
the setting would delete items, the settings UI asks first. "Erase History" deletes every history
item and keeps pinboards.

## 6. Paste Queue

* Toggled by its shortcut (default **⇧⌘C**, configurable) or from the menu bar.
* A small floating window at the top right of the screen lists the queued snippets, shows the
  direction and has a close button. Each row has a remove action.
* While open: each new capture is appended to the queue. **⌘V is intercepted** globally. Each press
  writes the next snippet to the pasteboard, then synthesizes ⌘V into the frontmost app and removes the
  snippet. The next snippet is the oldest in *FIFO* mode (the default) and the newest in *LIFO* mode.
  The direction can be toggled at any time.
* When the queue is empty the ⌘V intercept is released, so ⌘V behaves normally. Closing the queue
  clears it and releases the intercept.
* The intercept is unregistered while the synthesized ⌘V is posted, so it can't loop.

## 7. Pause, menu bar, settings

* **Pause** for 15 minutes, 1 hour, 8 hours, or until resumed. It resumes automatically at
  `resume_at`. While paused, nothing is captured, the popup header shows "Paused until HH:MM" and the
  menu bar icon (Copywren's own wren glyph) is dimmed.
* **Menu bar item** (when "Show in menu bar" is on) offers Open Copywren, Paste Queue, Pause ▸, Resume,
  Settings…, Erase History…, and Quit.
* **Settings window**: General (direct paste, always paste as plain text, sound effects, show in menu
  bar), History (keep history, erase), Privacy (ignore confidential, ignore transient, show during
  screen sharing, ignored-apps list with remove, a bundle-ID field, and one-click suggestions from
  recently seen apps), Shortcuts (activation and Paste Queue shortcuts recorded by pressing them;
  quick-paste and plain-text modifiers). Shortcuts are stored as text such as `shift+cmd+v`.
* Settings persist as JSON in `~/Library/Application Support/Copywren/settings.json`. The database is
  `…/Copywren/copywren.sqlite`.
* Sounds use the system sounds "Pop" (copy) and "Tink" (paste) when enabled. Default: off.

## 8. Edge cases

* Very large text: the preview truncates at 2 000 chars, but the full payload is stored and pasted.
* Payload over 50 MB: not captured.
* Copying the same content twice: one history item, moved to the front.
* Copying content that only exists in a pinboard: a new history item is created; the pinboard is
  unchanged.
* Deleting the selected card: the selection moves to the next card (or the previous one, at the end).
* A deleted pinboard deletes its items (with confirmation). The History tab can't be renamed or deleted.
* Search with no results shows "Nothing found". An empty tab shows an empty-state message.
* Search tokens: a token equal to a type word (`text`, `link`, `image`, `color`, `file`, plus plurals
  and `url`, `files`) becomes a type filter. A token that is a prefix (≥ 3 chars) of a known source
  app name becomes an app filter. If no item matches with the app filter applied, it falls back to a
  content term. All remaining tokens must appear (case-insensitive) in the preview text, title or
  app name. Queries search the current tab only.
* Accessibility revoked mid-session: paste falls back to copy-only.
* Multiple displays: the popup opens on the display containing its anchor (the caret or the pointer).
* The frontmost app doesn't expose its caret (some Electron and Java apps): the popup opens at the
  mouse pointer.
* Paste target quit before pasting: the item is still copied, and ⌘V is posted to whatever is frontmost.
